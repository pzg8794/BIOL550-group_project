# BIOL550 Group Project Reports

This repository contains all written reports for the BIOL550 group project, including both group and individual submissions. The goal is to keep all project documentation organized, accessible, and well-documented for reference and collaboration.

## Structure
- **main.tex**: Main LaTeX source for the current report (group or individual).
- **main.aux, main.fdb_latexmk, main.fls, main.xdv**: Auxiliary files generated during LaTeX compilation.
- Additional reports and write-ups will be added as new files (e.g., `individual_writeup.tex`, `summary_report.tex`, etc.).

## Usage
1. Edit or add your report as a new `.tex` file or update `main.tex` as needed.
2. Compile LaTeX files using your preferred tool (e.g., `latexmk -pdf main.tex`).
3. Keep auxiliary files for reproducibility, or add them to `.gitignore` if not needed.

## Organization Tips
- Name new reports descriptively (e.g., `week2_individual_writeup.tex`).
- Add a section to this README for each major report or submission.
- Use comments in your `.tex` files to clarify authorship and purpose.
