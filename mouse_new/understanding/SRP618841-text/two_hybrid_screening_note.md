# Two-hybrid screening reference note

## Reference

- Wikipedia overview:
  - `https://en.wikipedia.org/wiki/Two-hybrid_screening`

## Why we are keeping this

We are using two-hybrid screening as a conceptual reference when discussing interaction-oriented biology in the `SRP618841` project. It is useful because it frames a common biological question:

- if one gene or regulator looks important,
- what interacting partner(s) or linked regulatory relationships might help explain the phenotype?

## How it helps this project

For the current DRG injury dataset, this reference is helpful when we talk about:

- `Ahr`
- `Hif1a`
- `Arnt`
- interaction-centered biological interpretation

It gives us a familiar interaction language for thinking about:

- shared partners,
- regulatory coupling,
- pathway crosstalk,
- and why one regulator may matter only in the presence or absence of another.

## Important limitation

This does **not** mean the current RNA-seq dataset is itself a two-hybrid assay.

Instead, we are using two-hybrid screening as:

- a conceptual reference for interaction biology,
- a way to discuss partner-dependent mechanisms,
- and a reminder that expression patterns alone do not directly prove physical interaction.
