Mouse RNA-Seq — GO Interpretation and Follow-up

BIOL550 Weekly Report — Apr 16, 2026

What I accomplished since the previous report

Since the previous report, I focused on the interpretation stage of the fasted/fed mouse differential-expression analysis using mouse_differential_expression_ff_shinygo_style.ipynb together with the follow-up notebooks mouse_differential_expression_ff_go_followup.ipynb and mouse_differential_expression_ff_go_deeper.ipynb. To avoid repeating earlier reports, I concentrated on the parts of the GO follow-up that add genuinely new information for the paper: term redundancy, gene-level support across top terms, and the matched comparison between the FF and CRE branches.

The main new result this week is that the top FF GO signal is not just a collection of similar labels. The ShinyGO-style chart, tree, and network views show that the strongest upregulated terms cluster into a connected immune/inflammatory module with related metabolic and regulatory sub-branches. In addition, the genes view makes it possible to see which genes are repeatedly supporting the leading terms, which helps distinguish core driver genes from one-off term membership.

I also extended the interpretation by comparing the FF and CRE branches with a matched workflow. That comparison is useful because it lets us separate what is broadly shared across branches from what is more FF-specific. This is a better paper-facing analysis than simply listing enriched terms, because it asks whether the same genes are actually driving the overlap or whether the overlap is mostly at the label level.

Methods used

This week’s work was centered on downstream interpretation, not re-running the full differential-expression workflow. I used the existing fasted/fed notebook as the base analysis source and then used the GO follow-up notebooks to inspect the results from four complementary angles: a ranked chart view, a tree/network view of related terms, a genes view showing which genes support the top terms, and a matched FF-versus-CRE comparison.

The gene-support analysis is one of the most useful additions because it goes beyond term names. Instead of only asking which GO labels are significant, this step asks which genes recur across the top enriched terms. That gives a more grounded interpretation of the FF branch and makes it easier to identify genes that are central to the current biological story.

The second new analysis is the FF-versus-CRE comparison. For shared or similar enriched terms, I examined whether support comes from FF-only genes, shared genes, or CRE-only genes. This helps determine whether branch overlap reflects genuinely shared biology or simply similar high-level term labels with different underlying contributors.

Problems encountered

The main issue this week was not a failure in the analysis itself, but making sure the report added something new. Earlier reports already covered the core differential-expression workflow, so the challenge here was deciding which parts of the GO notebooks truly extend the project instead of repeating background material. That required keeping the emphasis on gene-support structure, term clustering, and the FF-versus-CRE comparison.

Another challenge is that the notebook sequence produces more outputs than can fit cleanly into a weekly report. To keep the message focused, I treated this as a synthesis step and selected the analyses that most directly improve the paper: identifying core supporting genes, showing how the top FF terms cluster together, and clarifying which GO themes are shared or distinct across the FF and CRE branches.

Goals for the coming week

Next week I want to convert the current GO interpretation into material that is directly usable for the final paper. The first goal is to take the strongest FF pathway groups and connect them to the most repeatedly supporting genes so that the Results section can explain not only which pathways were enriched, but also which genes make those pathways credible.

That should help the professor evaluate the final direction of the paper more easily and should make the remaining work focus on interpretation quality rather than producing another round of repetitive plots.
