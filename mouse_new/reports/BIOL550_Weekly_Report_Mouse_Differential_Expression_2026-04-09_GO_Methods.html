Methods used

This week’s methods work had two main extensions. First, for the GO follow-up, I re-ran the FF GO Biological Process query through the g:Profiler API with retained term-gene membership, then built three local companion views from that output: a ranked chart, a clustering tree based on shared genes, and a network based on shared-gene overlap. Second, for the paper draft, I translated the computational workflow into manuscript prose organized as four pipeline stages so that the new GO work and the Methods draft stayed tied to the same reproducible analysis path. 

# chart / network summary
up = pd.read_csv(
    FF_DIR / "gprofiler_up_with_membership.tsv",
    sep="\t"

up["neglog10_fdr"] = -np.log10(up["p_value"])
up["fold_enrichment"] = (

# tree / heatmap similarity
members = pd.read_csv(
    FF_DIR / "gprofiler_up_term_gene_membership.tsv",
    sep="\t"
)
term_sets = members.groupby("native")["gene_id"].apply(set)

for a in term_sets.index:
    for b in term_sets.index:
        overlap = len(term_sets[a] & term_sets[b]) / \
                  max(1, len(term_sets[a] | term_sets[b]))
        sim.loc[a, b] = overlap

sns.heatmap(sim)
linkage(1 - sim)

Problems encountered

The main difficulty this week was deciding how to interpret enriched GO terms without overstating how many distinct biological stories were present. The raw GO output still contains many overlapping labels, and significance alone can make those terms look more independent than they actually are. The chart, tree, and network views helped address most of that by showing when multiple enriched terms are supported by the same underlying gene neighborhood.

A second issue is that the GO result remains asymmetric. The clearest and strongest structure still sits in the FF upregulated branch, which is analytically useful but means the GO story should not be presented as fully balanced across directions. On the writing side, the Methods draft now has a much cleaner structure, but it still has to stay aligned with the group’s broader paper outline while keeping the main side-specific contrast at the center.
