Methods used

This follow-up keeps the same DESeq2 result framework from the canonical mouse_new notebook, but the emphasis is now interpretive rather than purely procedural. Following class feedback from Apr 1, I used PCA as the first sanity check, compared signal strength across contrasts using the DE plots, and then applied an ordered-p-value / cumulative bend-point method to narrow large gene lists into smaller follow-up sets for enrichment and story selection.

  • PCA is used first to separate intrinsic sample structure from contrast-specific signal.
  • Bend-point filtering defines a narrower core follow-up set from the larger significant-gene pool.
  • GO / KEGG / Reactome enrichment is run on bend-point–selected genes for the main side-specific contrasts and geno_in_contra.
  • The goal is to understand the data and choose a defensible story, not just to generate more plots.

Problems encountered

The main challenge this week was deciding how to interpret the large DE output without forcing a misleading story. The raw significant-gene counts were too large to use directly, and the genotype signal was easy to over-read if labels were examined without first grounding them in the PCA structure. Deciding which figures explained the data versus which were redundant was also non-trivial.

Class feedback helped by pushing toward structure-first interpretation, bend-point–based narrowing, and cleaner figure choices. The side-specific DRG contrasts stay central, geno_in_contra stays as supporting context, and the weaker genotype/interaction branches remain exploratory rather than being over-promoted.
